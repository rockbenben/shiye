# 标识

源头是这个目录里的两个 `.svg`，PNG 全部由 `render.mjs` 生成——**不要手改 PNG**。

```
npx electron brand/render.mjs
```

| 文件 | 用处 |
|---|---|
| `mark.svg` | 印。源头 |
| `logo.svg` | 横排组合（印 + 字标）。源头 |
| `../desktop/build/icon.png` | 桌面版应用图标（electron-builder 从它生成 .ico） |
| `../web/public/icon.svg` | 网页标签页图标（`mark.svg` 的副本） |
| `social-card.html` | 社交卡。源头 |

| `mark-512/64/32.png`, `logo.png` | 各处要用位图时取现成的 |

## 这个印是什么

**圈点。** 白文没有标点，读的人在字旁画小圈，把连成一片的字断成句、标出要紧处
——这正是这个应用对一句随手记做的事。三道竖笔是你写的那几行（竖排从右往左读，
所以最右那行最长、最左那行收在半途，像一段话正好写完），群青那一枚圈嵌在行间，
落在句读该落的地方。

名字也不是装饰：师爷是清代主官自掏腰包请的私人幕僚，住在签押房，每天做三件事
——**拆**（拆封分类当天的案牍）、**拟稿**（把杂乱的呈文理成条陈）、**点卯**
（管循环簿，什么时候该办什么）。跟这个应用的三步是同一件事。

而群青是**朱批的倒置**：批注权从上级换成了幕僚，颜色从朱换成了群青，配给制没变。

## 规矩

- **颜色一个都不新引**，全部取自 `web/src/theme.css` 的 `:root`：
  纸 `#FAF8F5` / 界 `#D4CEC3` / 你的墨 `#211F1D` / 师爷的墨 `#2E3ED4`。
- **群青只出现一次**。这是应用的第一条视觉规矩（「配给制，只标 AI 产出」），
  标识自己不能带头破。**旧图标整块底都是群青，那是它被换掉的头一个理由。**
- 社交卡上：你写的那句是石墨黑，拆出来的任务标题也是石墨黑（那是你的事），
  只有圈和它**推断出来**的时间是群青——跟 `TaskCard.tsx` 真实的渲染规则一致。
  那张卡不是在介绍产品，它是产品的一页样张。
- 字标沿用应用顶栏那一套：宋体、`0.24em` 字距，后面一枚群青的点。那颗点跟印里
  那一枚圈是同一样东西，只是小到挖不出中间的空。

## 一个坑

`logo.svg` 里的字是**活字不是轮廓**（这台机器上有宋体，`render.mjs` 渲出来就是
它该有的样子）。直接把那个 `.svg` 挂到 GitHub 或别人的网页上，会退成对方环境里
的衬线体——要贴到别处，用 `logo.png`。
